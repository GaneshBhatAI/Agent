Welcome to the Control Room. Please authenticate with your GitHub Personal Access Token (PAT) to synchronize workflows, runners, and bot scripts.

How to get a GitHub PAT Token?

  1. Sign in to your account at github.com
  2. Click your profile picture in the top-right corner, then choose Settings
  3. Scroll down the left sidebar menu and click on Developer settings
  4. Under Personal access tokens, click on Tokens (classic)
  5. Click the Generate new token dropdown -> select Generate new token (classic)
  6. Give your token a descriptive name (e.g., AgenticOrchestrator)
  7. Under scopes, select check boxes for:
    • repo (Full control of private repositories)
    • workflow (To manage runner triggers)
  8. Click Generate token at the bottom of the page
  9. Copy the token string (starts with ghp_) and paste it on the left form field
